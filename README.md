# Telegram бот для поиска и скачивания музыки из SoundCloud

## Что умеет
- Ищет треки через команду `/search <запрос>`.
- Показывает список найденных треков кнопками.
- Скачивает выбранный трек и отправляет в чат как audio-файл.

## Установка
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка
1. Скопируйте `.env.example` в `.env`.
2. Укажите токен бота от `@BotFather`:
   - `TELEGRAM_BOT_TOKEN=...`

## Запуск
```bash
python bot.py
```

## Команды
- `/start` — инструкция
- `/search <название>` — поиск трека

## Замечания
- Бот использует `yt-dlp` для поиска и скачивания с SoundCloud.
- Телеграм ограничивает отправку файлов ботом по размеру (в коде установлен лимит 49MB).
