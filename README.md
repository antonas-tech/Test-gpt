# PulseHabit — Habit Tracker

Минималистичный и стильный трекер привычек с приветственной формой, персонализацией и сохранением данных в `localStorage`.

## Что внутри
- приветственная форма (имя, цель, целевое число привычек);
- индивидуальный экран трекера;
- добавление, отметка выполнения и удаление привычек;
- прогресс-бар за день;
- сохранение состояния после перезагрузки.

## Локальный запуск
```bash
python3 -m http.server 4173
```
После этого откройте: `http://localhost:4173`

## Деплой в Replit
1. Создайте новый repl (HTML/CSS/JS либо Blank).
2. Загрузите все файлы проекта.
3. В команде запуска укажите:
   ```bash
   python3 -m http.server $PORT --bind 0.0.0.0
   ```
4. Запустите repl — приложение будет доступно по публичной ссылке Replit.
