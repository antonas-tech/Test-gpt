# Мастер-промпт для Claude Code: сайт «Семейное древо» (проект под ключ, от А до Я)

Ты — **Lead Full-Stack Engineer + Product Designer + DevOps + Security Engineer + QA + Tech Writer**.  
Твоя задача: создать **полностью готовый к запуску сайт** для семейного использования (не массовый продукт), с уникальным премиальным дизайном, реальной БД, регистрацией, чатом, админкой и богатым функционалом.

Критично важно: результат должен быть **реально рабочим**, не «демо-рыбой».

---

## 0) Формат итоговой сдачи (обязательно)

1. Сгенерируй полный проект и все файлы кода.
2. Убедись, что проект запускается локально одной командой (или 2 понятными командами).
3. В конце подготовь **один ZIP-архив** со всем проектом.
4. В ответе дай:
   - краткую инструкцию запуска,
   - тестовые логины,
   - список реализованных фич,
   - список известных ограничений (если есть),
   - путь/название zip-файла.
5. Никаких «псевдо-кодов» и «набросков» — только готовое решение.

## 1) Общая идея продукта

Сайт для меня, друзей и родственников. Люди должны заходить туда с удовольствием: смотреть обновления семьи, фото, истории, общаться, находить родственников, сохранять память поколений.

Проект должен ощущаться как **цифровая семейная реликвия**: красиво, тепло, современно, эмоционально и технологично.

---

## 2) Техстек (выбери и зафиксируй сразу)

Выбери **один современный, практичный стек**, например:
- Frontend: Next.js (App Router) + TypeScript + Tailwind + Framer Motion
- Backend: Next.js API Routes / NestJS / Express (на твой выбор, но единообразно)
- DB: PostgreSQL (обязательно реальная БД)
- ORM: Prisma
- Auth: NextAuth / JWT + refresh token
- Realtime chat: WebSocket (Socket.IO) или Pusher
- Хранение фото: локально + abstraction под S3 (или сразу S3-compatible)
- Кэш/очереди (по возможности): Redis
- Поиск: PostgreSQL full-text + индексы

Важно:
- Выбирай решения, которые легко поднять локально.
- Если используешь Docker — приложи docker-compose.
- Если без Docker — дай пошаговую установку зависимостей.

## 5) Вкладка «Древо» (ключевая)

Нужно не банально, а художественно и функционально.

### 5.1 Визуальная концепция
- Реалистичное стилизованное дерево (SVG/Canvas/WebGL на выбор).
- На концах веток — **светящиеся точки/узлы** (каждая точка = человек).
- Логика вертикали:
  - чем ниже ветка — тем старшее поколение,
  - чем выше — дети/потомки.
- Верхние узлы могут быть «пустыми слотами» для будущих детей (чтобы дерево расширялось).

### 5.2 Интерактив
- Zoom / pan / перетаскивание дерева.
- Hover карточка человека (фото, ФИО, годы жизни, степень родства).
- Клик по узлу → открывается профиль человека.
- Добавление нового родственника из узла (+).
- Линии родства (родитель-ребенок, супруги) с визуальными различиями.
- Фильтры: живые/ушедшие, по фамилии, по ветви, по поколению.
- Поиск по имени и быстрый переход к узлу.

### 5.3 Данные по человеку
- ФИО
- девичья фамилия
- дата рождения / смерти
- пол
- биография
- фото
- контакты (опционально, с privacy)
- связи (родители/дети/супруг)
- важные факты (награды, профессия, города жизни)

### 5.4 «Вау»-фишки для дерева
Добавь:
- режим «Временная шкала» (ползунок по годам — показывать только тех, кто уже родился к выбранному году)
- режим «Тепловая подсветка родства» (кто ближе к выбранному человеку)
- автоматическую проверку логических ошибок (например, ребенок старше родителя)
- мягкие анимации роста веток при добавлении новых членов семьи

## 6) Вкладка «Галерея»

Нужна красивая плавная лента с живыми анимациями.

### Функции
- Masonry/лента карточек фото.
- Плавное появление при скролле.
- Каждое фото: подпись + привязка к человеку/событию.
- Под фото: краткое сведение о человеке.
- Лайк/реакции (сердце, огонь, улыбка) для семейного взаимодействия.
- Комментарии к фото (с модерацией).
- Lightbox просмотр.
- Альбомы: «Свадьбы», «Путешествия», «Детство», «Архив», и т.д.
- Умный фильтр: по человеку, году, событию, месту.

### Доп. идеи
- «Фото дня» на главной.
- Авто-слайдшоу «Ностальгия» из архивных фото.
- До/после (для старых фото после реставрации).

- Кастомные hover/focus состояния.
- Эффекты стекла/свечения использовать умеренно и со вкусом.
- Полная адаптивность (desktop/tablet/mobile).
- Accessibility: контраст, aria-label, видимые focus ring, навигация с клавиатуры.

Добавь light/dark режим с красивыми темами.
